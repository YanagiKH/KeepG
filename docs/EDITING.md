# KeepG 0.7 編輯與多選操作手冊

## 設定分類

設定頁提供外觀、瀏覽、編輯、AI 助理、安全與維護六個標籤。搜尋同時比對原文與目前語言，可跨分類找項目。外觀含系統/淺色/深色、Android 12+ 桌布配色、格數、版面與動畫；編輯含 PNG/JPEG/WebP 預設輸出、品質與輔助線。維護可清除縮圖、OCR 索引、檢閱/匯出日誌與只重設外觀，不會重設密码或移除模型。

## 靜態圖片（Full）

開啟圖片 → 編輯。明確選擇「移動圖片」、「裁切」、「圖層」，避免一個手勢同時變更多個物件。移動模式可拖曳、雙指縮放和旋轉；裁切模式可拖四角或內部，並選自由、原始、正方形、4:3、16:9 等比例。精準滑桿提供位置、縮放、旋轉、亮度、對比、飽和度，並可水平/垂直翻轉。

文字圖層可新增、選取、修改文字、顏色、粗體、陰影、縮放、旋轉、前後順序，再於畫布拖曳。最多 30 圖層；復原/重做最多 40 筆，以一次拖曳或滑桿操作為單位。裁切和輸出共用標準化座標與繪製路徑，輸出另存副本。最大輸出邊與約 8MP 解碼/輸出限制用於控制記憶體；不宣稱無限制全解析度編輯。

PNG 保留透明；JPEG 透明區填白且品質影響檔案大小；WebP 依 Android 編碼器支援。背景移除仍使用 Full 的既有 ML Kit/角落色彩工具。不要把 App-level 保護鎖當成匯出加密：輸出的新副本預設是普通媒體。

## GIF 動畫（Full）

開啟 GIF → 編輯 → 選「編輯動畫」或「編輯單一影格」。後者明確儲存靜態副本，不會聲稱保留動畫。

動畫模式拖時間軸選範圍，設定速度、1–24 FPS、反向播放、循環次數及 240/480/640px 最長邊。按「編輯裁切、色彩與圖層」使用共用圖片編輯器，儲存變更後套用到每一影格，最後另存動畫。

匯出最多 30 秒/360 影格，採 256 色調色盤量化，透明填白，並非無損/原調色盤保留。輸入限 16MiB，並在原生解碼前檢查尺寸、影格、資料區塊及總解碼配置上限。超限會拒絕，不嘗試耗盡裝置記憶體。匯出中可取消；未完成的 MediaStore 項目會清理。

## 影片（Full）

開啟影片 → 編輯。拖曳時間範圍或輸入開始/結束毫秒；用靜態預覽位置滑桿選代表影格，直接拖曳裁切框或調整四邊。可旋轉、翻轉、0.25–4 倍速、靜音與原始/480/720/1080 高度；「播放編輯預覽」套用裁切、旋轉與速度。

新編輯器使用 Media3 Transformer 輸出新 H.264/AAC MP4，並非僅關鍵影格的 remux。需要裝置支援來源解碼和目標編碼，長片、HDR、特殊編碼器或 GPU 驅動仍可能失敗。預覽不保證裝置能匯出。取消時先停止原生處理，再清理暫存與未完成輸出；原始檔不以寫入模式開啟。

## 相簿內多選

開啟裝置相簿、收藏集或最愛，長按一張可見媒體即可開始多選。再點其他媒體切換選取；操作列有全選、最愛、分享、收藏集、保護、保險庫、分析、刪除（依版本）。小螢幕操作列可橫向捲動。

全選限目前相簿/收藏集的可見且已解鎖項目，不會切回照片總覽或選到其他相簿。「清除選取」仍留在目前相簿；返回鍵先清除選取，再返回總覽。收藏集中的批次「移除」只刪除參照，裝置檔案保留。鎖定或目錄變動會重新驗證選取範圍。
